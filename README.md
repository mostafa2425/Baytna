# Baytna 🏠

**بيتنا — مشتريات بيتك، كلها في مكان واحد.**

Baytna is a personal household shopping assistant built with Next.js, TypeScript, Ant Design, SCSS, and Supabase.

## Product

- Arabic by default, with full English support.
- RTL/LTR support.
- Product catalog with categories, base products, aliases, brands, variants, quantities and units.
- Shopping lists and shopping mode.
- Purchase and price history.
- Favorites, stores and Buy Again.
- Receipt upload.
- Future: price intelligence, budgets, smart suggestions and AI shopping assistance.

## Roadmap

1. **Phase 1 — Simple:** Catalog → List → Buy → Record Price
2. **Phase 2 — Personal:** Favorites → History → Buy Again → Stores
3. **Phase 3 — Smart:** Price Comparison → Unit Price → Budget → Suggestions
4. **Phase 4 — AI:** Recipes → Missing Items → Smart Shopping

## Stack

- Next.js + TypeScript
- Ant Design
- SCSS
- Supabase PostgreSQL / Auth / Storage
- Vercel
- GitHub
